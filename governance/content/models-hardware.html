Mapped against the 2026 Mac Studio lineup: M5 Max — 18-core CPU, up to 40-core GPU, up to 128 GB unified memory, ~614 GB/s bandwidth, from $2,499 (36 GB base) — and M5 Ultra — up to 36-core CPU, up to 80-core GPU, up to 512 GB unified memory, 1.2 TB/s bandwidth, from $5,499 (96 GB base; 256 GB available now, 512 GB ships late October 2026). Apple Silicon shares one unified memory pool across CPU/GPU/Neural Engine, so unlike a discrete GPU there's no separate VRAM ceiling below the machine's total RAM — that's specifically why the 235B-parameter Qwen3-VL model only becomes self-hostable at all on the Ultra tier, not because of raw compute. Fitting in memory is not the same as fitting in time, though: an M5 Ultra's 1.2 TB/s is well short of a datacenter GPU's several TB/s, so a model that loads fine on a Mac Studio will still generate noticeably slower than the same model on the multi-GPU hardware OpenRouter actually runs it on.

† these model ids reference releases after my Jan 2026 knowledge cutoff — sizes are unconfirmed rather than guessed; check OpenRouter's model page before relying on them.
